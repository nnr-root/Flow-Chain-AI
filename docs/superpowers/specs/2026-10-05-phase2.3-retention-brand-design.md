# Phase 2.3 — Retention, Auto-SFX & Brand Layers: Design Spec

- **Date:** 2026-10-05
- **Status:** Approved (brainstorming sections 1–4)
- **Scope:** Sub-project 2.3 of Phase 2, the last one. Builds on Phase 1
  (`2026-10-02-phase1-cli-poc-design.md`), 2.1 (`2026-10-03-phase2.1-remotion-render-engine-design.md`) and 2.2
  (`2026-10-04-phase2.2-content-intelligence-design.md`), including the findings recorded in their live-verification
  sections.

## 1. Goal

Make the first seconds grab attention, make the video sound finished, let a brand own the look, and stop paying for
video nobody sees:

1. **Hook:** a snap zoom, a bold hook title written by Gemini and an impact sound in the first 3 s.
2. **Sound:** automatic transition sound effects, an audible but polite music bed, and fades that finish cleanly.
3. **Brand:** a brand kit (logo watermark, font, colours) and a character bible plus a shared seed for steadier
   characters.
4. **Cost:** a 16-word narration cap and per-model clip-length profiles, so nearly every Kling clip is the 5 s one
   ($0.25 instead of $0.50).

### Non-goals

The RunPod / Wan / self-hosted Flux providers (they will add a video profile, §7), reference-image character
conditioning, an outro or music tail, Gemini choosing sound effects, animated logos, several brand kits per run, a
manifest schema bump.

## 2. Decisions

| Topic | Decision |
|---|---|
| Architecture | Hook, sound-effect cues and the watermark are `RenderProps` data built by the pure `buildRenderProps`; new `HookLayer` and `BrandLayer`, cues in `AudioLayer`. One render pass; `rerender` toggles them for free |
| Hook text | Gemini writes a required `hook` (2–6 words) in the script call; `--hook "TEXT"` overrides; `--no-hook` turns it off |
| Sound effects | Synthesized once with ffmpeg by a committed script (seeded noise), bundled in `assets/sfx/`; no runtime synthesis, no licences |
| Music duck | Duck to 40 % (was 18 %), 10-frame S-curve ramps (was 6-frame linear) |
| Fade fix | Transition blend `q = (local + 1) / 2h` (was `local / 2h`, which stopped at 90 %) |
| Brand kit | A folder with `brand.json`; the look (logo, font, colours) is render-only and copied into the run; the character bible is frozen at creation |
| Character consistency | Text bible (`--characters` or the kit's) enforced into `styleBible.characters`, plus one shared Flux seed per run |
| Cost | `MAX_NARRATION_WORDS` 22 → 16; clip length comes from a per-run video profile (`kling-v2`: 5 s clip for narration ≤ 6.0 s, stretched by the fit step) |
| Compatibility | Everything that changes what is bought is frozen per run and absent on older runs, so their cache keys never change; only the free render re-runs |

## 3. Data Model

### 3.1 Script

- `LlmScript` gains `hook: string` (required; described to Gemini as "2–6 punchy words that tease the payoff without
  giving it away; no emojis or hashtags"). `validateScript` adds a post-check that rejects an empty hook or one longer
  than 6 words (a one-word hook is allowed).
- The stored `Script` gains `hook?: string`, so older manifests load.
- `MAX_NARRATION_WORDS` becomes 16. The prompt says "at most 16 words, ideally 12–15". Stored scripts are never
  re-checked, so older runs are unaffected.

### 3.2 Run request (frozen at creation; changing them would change paid work)

| Field | Meaning |
|---|---|
| `characters?: string` (≤ 600 chars) | Character bible: `--characters`, else the brand kit's `characters` |
| `seed?: number` (integer 0 … 2³²−1) | Shared Flux seed: `--seed`, else random for new runs |
| `videoProfile?: "kling-v2"` | Clip-length profile; new runs get `kling-v2`; absent = `kling-v1` (§7) |

### 3.3 Render options (change only with `rerender`, always free)

| Field | Default | Meaning |
|---|---|---|
| `hook: boolean` | `true` | Show the hook when there is text |
| `hookText?: string` (1–60 chars after trim) | — | Overrides the script's hook |
| `sfx: boolean` | `true` | Play sound-effect cues |
| `sfxGain: number` (0–1) | `0.6` | Sound-effect level relative to the narration |
| `brand?: BrandLook` | — | The kit's look, with paths relative to the run directory (§6.2) |

Older manifests parse with the defaults filled in. Their render options differ only in render output, which is free.

### 3.4 Render contract (`RenderProps`, `src/media/remotion/props.ts`)

```ts
hook: null | { text: string; endFrame: number; zoomFrom: number; zoomFrames: number };
brand: null | { logo: string; position: Corner; widthPct: number; opacity: number; marginPct: number };
audio.sfx: Array<{ src: string; frame: number; gain: number }>;
```

`captions.style` is the effective caption style after the brand overrides (§6.3). The hook title uses that same
style, so the hook needs no style of its own.

### 3.5 Effective values (pure helpers, `src/stages/look.ts` and siblings)

- **Hook text:** `render.hook ? (render.hookText ?? script.hook) : null`, trimmed; empty → `null`.
- **Caption style:** explicit name → `CAPTION_STYLES[name]`; `"preset"` → the preset's caption, or `hormozi`. Then
  the brand's font, `colors.text` → `color` and `colors.accent` → `activeColor` replace those fields when set.
- **Video profile:** `PROFILES[request.videoProfile ?? "kling-v1"]`.

## 4. Hook Generator (first 3 s)

- **When:** only when the effective hook text exists. Runs scripted before 2.3 have no hook, so they never show one.
- **Timing:** `endFrame = min(3 s × fps, frames of scene 1)`. Captions stay on: the narration starts at frame 0 and the
  two areas do not overlap.
- **Snap zoom:** the scene and transition layers are wrapped in one container scaled by `zoomAt(f)`:
  `1 + (zoomFrom − 1) · (1 − easeOutCubic(f / zoomFrames))` for `f < zoomFrames`, else 1; `zoomFrom` 1.15,
  `zoomFrames` 12 (0.4 s), transform origin at the centre. Captions, the hook title and the watermark are not zoomed.
- **Title (`HookLayer`, above the captions):**
  - The hook text, upper-cased, in the caption style's font and weight.
  - Font size is `min(11 % of the short side, fitText(85 % of the width))`, on one line, centred about 38 % from the
    top of the frame.
  - Colour is the style's `color`, with the last word in `activeColor`, plus the style's stroke and shadow.
  - It pops in from 0.6× to 1× over 6 frames (easeOutCubic), holds, then fades out linearly over the last 8 frames
    before `endFrame`.
  - It loads its font through the same delay/continue hook as the captions, so no frame is captured before the font
    is ready.
- **Impact:** the hook adds a sound-effect cue `impact` at frame 0 (§5).
- **Edge cases:** an empty or whitespace hook means no zoom, no title and no impact. An overlong hook is shrunk by
  `fitText`, never wrapped or cut.

## 5. Auto Sound Effects & Audio Polish

### 5.1 Sound files

`scripts/make-sfx.ts` (npm `make:sfx`) synthesizes the three sounds with ffmpeg (`anoisesrc` with a fixed seed,
`sine`, filters and envelopes) and writes 44.1 kHz stereo MP3s to `assets/sfx/`. The files are committed; renders
never synthesize. `doctor` checks that they exist.

| File | Sound | Length | Loudest point |
|---|---|---|---|
| `impact_boom.mp3` | low sine sweep 110 → 40 Hz, fast attack and exponential decay, plus a short noise burst | ≈ 1.2 s | ≈ 0 s |
| `whoosh.mp3` | pink noise, band-pass sweeping upward, rise-then-fall envelope | ≈ 0.5 s | 0.25 s |
| `pop.mp3` | 900 → 500 Hz blip | ≈ 0.08 s | ≈ 0 s |

### 5.2 Cue rules (pure `sfxCues`)

| Moment | Sound | Frame | Base gain |
|---|---|---|---|
| Hook shown | `impact` | 0 | 1.0 |
| Cut with `zoom` or `blur` | `whoosh` | cut − 8 (peak on the cut), clamped ≥ 0 | 0.8 |
| Cut with `glitch` or `cut` (a real cut, not a seam) | `pop` | cut | 0.7 |
| Cut with `fade` or `dissolve` | none | — | — |
| Seam | none | — | — |

The cue gain is `sfxGain × base gain`. With `render.sfx` false the list is empty. `buildRenderProps` publishes only
the files it uses.

### 5.3 Mix

- In `AudioLayer`, each cue is an `<Audio>` inside `<Sequence from={frame}>`.
- Sound effects do not duck the music and are not ducked.
- The final loudness pass (−14 LUFS, −1.5 dBTP) still runs last.

### 5.4 Music ducking

`BGM_MIX` becomes `{ duckTo: 0.4, rampFrames: 10, fadeOutFrames: 30 }`. The ramp shape changes from linear to the
existing `easeInOut` (cosine S-curve): `duckTo + (1 − duckTo) · easeInOut(distance / rampFrames)`. Speech detection
is unchanged (gaps < 0.35 s merged, 0.1 s padding). At the default music gain 0.35, the music under speech goes from
≈ 6 % to 14 % of full level.

### 5.5 Fade-end fix

`transitionLook` uses `q = (local + 1) / (2h)`. Fade, dissolve and zoom now reach exactly 100 % of the incoming scene
on the window's last frame, in equal steps. Blur already ended cleanly and is unchanged.

## 6. Brand Kit & Character Bible

### 6.1 Kit format

A folder with `brand.json`, validated with zod when a run starts or a rerender applies it:

```json
{
  "name": "Example",
  "logo": "logo.svg",
  "watermark": { "position": "top-right", "widthPct": 14, "opacity": 0.8, "marginPct": 4 },
  "font": { "family": "Example Sans", "file": "ExampleSans-Bold.ttf", "weight": 700 },
  "colors": { "text": "#FFFFFF", "accent": "#00E5FF" },
  "characters": "Nova: a woman in her 20s, short silver bob, cyan visor over the left eye, black techwear jacket"
}
```

- **Required:** `name` and `logo` (PNG or SVG).
- **`watermark` defaults:** `top-right`, 14, 0.8, 4. `position` is one of `top-left`, `top-right`, `bottom-left`,
  `bottom-right`.
- **Colours:** must be `#RRGGBB`.
- **Font:** must be a `.ttf` or `.otf` inside the kit.
- **Errors:** a missing file, a bad colour or an unknown key fails with one clear message before anything is bought.
- **Example kit:** `assets/brand/example/`, with a geometric chain-link logo in SVG (no text, so no font needed),
  accent `#00E5FF` and no font or characters.

### 6.2 The look (render-only)

- **Applying a kit:** `run --brand <dir>` (and `rerender --brand <dir>`) copies the logo and font into
  `runs/<id>/brand/` and stores `render.brand` with run-relative paths.
- **Removing a kit:** `rerender --no-brand` clears `render.brand`.
- **Rendering:** brand files are published from the run directory; bundled fonts still come from `assets/fonts/`.
- **Watermark:** `BrandLayer` is the top layer.
  - The logo sits at the chosen corner, its width is `widthPct` of the frame width (height keeps the aspect ratio),
    its margin is `marginPct` of the short side, and its opacity is as set.
  - It is never zoomed.
  - The default top-right corner keeps it clear of the captions and the platforms' bottom UI.

### 6.3 Captions and hook

The brand overrides the base caption style (§3.5): font (family, published file, weight), `color` and `activeColor`.
The captions stage's words-per-page are unchanged (they come from the base style).

### 6.4 Character bible and seed (frozen)

- **Bible:** `request.characters` comes from `--characters`, else the kit's `characters`.
  - The script prompt says: "styleBible.characters: use exactly: …; refer to these characters consistently".
  - After validation, `styleBible.characters := request.characters`. The script cache inputs add `characters`.
  - Image and motion prompts already include `styleBible.characters`.
- **Seed:** `request.seed` comes from `--seed`, else a random 32-bit integer chosen at creation.
  - Each keyframe uses `(seed + nonce of that scene's keyframes) mod 2³²`, so scenes share one seed and a reroll still
    gets a new image.
  - The keyframes cache inputs include the seed only when `request.seed` is set.

## 7. Narration Cap & Video Profiles

`src/video-profiles.ts`:

```ts
type VideoProfile = {
  id: "kling-v1" | "kling-v2";
  clipSec(narrationSec: number): number;           // seconds of video to buy for one scene
  costUsd(prices: Prices, clipSec: number): number;
};
```

| Profile | Rule | Used by |
|---|---|---|
| `kling-v1` | narration ≤ 5 s → 5, else 10 (Phase 1 rule) | runs without `videoProfile` |
| `kling-v2` | narration ≤ 6.0 s → 5, else 10 | new runs |

Both profiles compute their cost with the existing `videoCost`.

**Why 6.0 s.** Kling's 5 s clip is ≈ 5.04 s, so 6.0 s needs a stretch of ≈ 1.19×. That is inside the fit step's
existing `MAX_SLOW` of 1.25 (`slow`, not `slow+freeze`).

**Where the profile is used.** Every former use of `requestedSec`, and the Kling cost in the clips stage, goes through
the run's profile:
- the clips cache inputs, the purchase and the estimate;
- the `modes` stage's `PlanModesInput`.

**Wider types.** The clip-length type widens from `5 | 10` to seconds (`number`): `SceneState.clip.requestedSec`,
`VideoRequest.durationSec` and `PlanModesInput.scenes[].requestedSec`. A RunPod/Wan profile can then bill per second
without touching the planner. Older manifests still parse.

**Expected effect.** On the 2.2 live run, narrations of 6.2–6.7 s were billed as 10 s clips. With the 16-word cap
(≈ 5–5.7 s), all four become 5 s clips: video $1.00 instead of $2.00, run ≈ $1.35.

## 9. Compatibility

| Run made before 2.3 | Effect |

(2.1 `20261004-092335-2d87f4`, 2.2 `20261005-084047-8199d1`): only free stages may appear.

## 10. Testing (offline)

- **Unit:**
  - Hook: the effective-text rules; `zoomAt` at 0/6/12; the title's scale and opacity curves; `endFrame` with a short
    scene 1.
  - Sound effects: `sfxCues` for every transition, seams, the hook, clamping and `sfx: false`.
  - Ducking: the duck level and S-ramp values.
  - Fades: the fixed `q` reaches 1 on the last window frame for fade, dissolve and zoom.
  - Brand: kit validation (valid kit; each failure; defaults); caption-style precedence with and without a brand,
    explicit style and preset; watermark props.
  - Profiles: the boundaries 5.0 / 5.01 / 6.0 / 6.01 s for both profiles.
  - Script: `LlmScript` requires `hook` while `Script` does not; validation rejects 17 narration words and a 7-word
    hook.
- **Stages (fakes):**
  - The script stage enforces `characters` and keys on it.
  - Keyframes send `seed + nonce` to the fake image provider; a reroll changes it; no seed leaves the key as before.
  - Clips and `modes` use the run's profile.
  - `run --brand` copies the kit into the run.
- **Sound files:** the three files exist with the expected lengths; the whoosh's loudest point is at 0.25 ± 0.05 s.
- **Chrome:**
  - The hook title is visible at frame 15 and gone after `endFrame`; frame 0 is zoomed compared with frame 30.
  - With silent narration, a whoosh cue makes the audio around the cut louder than before it.
  - The watermark lights the top-right corner of a black frame while the opposite corner stays black.
  - A brand font renders.
  - The existing cross-fade test now expects 60 % at the window's middle frame.

## 11. Definition of Done

1. `npm test` and `npm run typecheck` pass. The 2.1 and 2.2 live runs still load and `rerender` for free.
2. A live `npm run smoke:brand` run (paid, after the user's approval) shows the hook, sound effects, the new duck and
   fades, and the watermark. Its clips use `kling-v2`, with no 10 s clip for narration ≤ 6.0 s. It is recorded in this
   spec.
