## Where each paragraph would go

The current `/terms` page (`web/app/(marketing)/terms/page.tsx`) is a placeholder that says the terms "are being written"; it has no
sections yet. So the places below are the ones the finished terms need, to be settled when the owner writes them:

Note on names: the licence text in A names the model and its maker. Everywhere else the notice names no model or provider. The
exemption for exactly this notice in `web/test/names.test.ts` (listed beside Stripe) is added only together with the approved text.
