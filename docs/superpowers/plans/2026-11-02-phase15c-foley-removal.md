### Task 18: remove Foley from the code

**Rulings that bind this task**
1. **Old runs (the Wan pattern):** a run made with `models.sound = runpod:<ep>/sound-foley@1` and Foley sounds on disk (`scenes[i].sound` with a Foley record: seed/guidance/steps/prompt, no `source: "clip"`) loads, `rerender` is free, `planRun` lists nothing paid for it, and its render plays the sounds on disk; a stage that would BUY a Foley sound for it refuses in the retired text style naming no model ("this run's scene sounds came from a sound engine this studio no longer uses; it can be re-rendered, but no sound can be bought for it"). `sound-foley` workflow ids parse to `{ provider: "retired" }`. The manifest's Foley record fields stay optional (they already are); `Sound` records with `source: "clip"` stay as they are. Foley prices (`runpodFoley*`) stay readable in `Prices`, ignored.
2. **New runs:** scene sound is the clip's own sound only. `request.sceneSound` is no longer set by any code path (the field stays in the schema for old runs); the rule "Foley wins the whole run" disappears: for a run without `request.sceneSound` everything behaves as today's LTX clip-sound branch. `FLOWCHAIN_SCENE_SOUND` stays accepted in the env schema and is ignored. `Health.sound` is true exactly when the LTX engine is on (`FLOWCHAIN_LTX=on` + endpoint, as `Health.speech`'s base), and `--sfx`/`--no-sfx` keep their meaning (render of the clip sound); the new-video form's sound switch and the hidden-form rule stay; its note must no longer say sound "adds to the price" (the clip's sound is free: change the wording and test it; the known wrong note from the ledger).
3. **Remove:** `worker-foley/` (all), its CI job (`foley`) and path filter in `.github/workflows/worker-image.yml`, `src/deploy/runpod.ts` and `scripts/runpod-deploy.ts` Foley parts (template/endpoint steps, `foleyGpus`, `chooseFoleyImage`, `foleyImageTag`, `--no-foley`, `RUNPOD_FOLEY_IMAGE`, `RUNPOD_FOLEY_ENDPOINT` write), `RunpodFoley` and `RUNPOD_WORKFLOWS.sound`, `foleyRates`/`FOLEY_RATES_MISSING`/`newRunSound`'s paid branch, the paid Foley branch of `src/stages/sound.ts` and its helpers that only it used (`src/sound.ts` pieces: the seed/guidance variations; `soundSeed` STAYS because the clips stage uses it), `src/media/sound-input.ts` if only Foley used it, `package.json` scripts that served only it, tests of the Foley worker/provider/stage (delete when their behaviour is gone with Foley; keep and adapt the clip-sound tests), `web/lib/engines.ts` internal-name entries for Foley stay (names must still never appear), `.env.example`/`deploy/server.env.example`, README ("Scene sound" section rewritten to the clip's own sound: how it is made, that a voice is never kept, the licence note about territory is REMOVED for Foley but the LTX licence notes stay), CLAUDE.md (layout row for `worker-foley/`, the scene-sound bullet in "How the pipeline is built" becomes the clip-sound statement, the spec table row for phase 12/14 stays as history with a short "Foley removed 2026-11-02" note), spec §13.12 (what was removed, the way back: git tag `foley-last` created on the commit BEFORE this task — a local tag; the registry image `ghcr.io/nnr-root/flowchain-foley:f-645a196b2127` stays). Keep `soundBible`/`soundPrompt` in the script (they steer the clip's `Audio:` sentence).
4. **Tests first:** before removing anything, add literal pins for an old Foley run fixture (load, free rerender, empty planRun, render props include its sound entries) and commit them; then the removal; a grep test: `src/` and `web/` (not tests, not `.next`) mention `sound-foley`, `RunpodFoley`, `foley` only in a short allowed list of files (retired-id handling, schema comments, names list); health test for the new `sound` rule; the form-note test.
